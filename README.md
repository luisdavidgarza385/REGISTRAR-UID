# REGISTRAR-UID (Selling Panel Web)

Panel de administración y gestión de UIDs para licencias, resellers y clientes (GOLDEN HACKS).

## 🚀 Características
- **Inicio de sesión**: Panel seguro de login (Admin & Reseller Dashboard).
- **Gestión de UIDs**: Alta, baja y consulta de licencias de jugadores.
- **Filtros en tiempo real**: Buscador instantáneo por UID o nombre de cliente.
- **Cálculo de expiración**: Indicadores de días restantes (Activo, Por Vencer, Expirado).
- **Integración API Backend**: Sincronización automática con servidor `apix.vypermods.com/bypass/vp`.
- **Persistencia y Copias de Seguridad**: Almacenamiento local + opción de exportar copia en JSON.

## 🛠️ Tecnologías
- HTML5 / CSS3 (Diseño Cyberpunk Glassmorphism con animaciones neón)
- JavaScript Vanilla ES6+
